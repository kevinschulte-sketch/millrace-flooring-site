# Millrace Flooring — protected site

Published drafts for the Millrace Flooring venture. All content pages are AES-256-GCM encrypted client-side; there is nothing readable in this repo without the password, which is shared out-of-band.

Built from the private `millrace-flooring` source repo via `tools/build_site.py` — do not edit these files by hand; they are overwritten on every build.
